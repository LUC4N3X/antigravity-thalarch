# Thalarch documentation

This directory contains maintainer-facing design and validation documentation that does not need to occupy the repository root.

- [`DESIGN-NOTES.md`](DESIGN-NOTES.md) — architecture, reliability model, routing, evidence, and design principles.
- [`HARD-GATES.md`](HARD-GATES.md) — deterministic anti-hallucination hooks, guarantees, limits, and validation.
- [`TEST-PROMPTS.md`](TEST-PROMPTS.md) — manual evaluation scenarios for behavior and regression testing.

Public project, installation, licensing, and legal entry points remain in the repository root.
